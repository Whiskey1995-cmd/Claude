# ВольтМаркет — сайт магазину електроніки

Статичний сайт-вітрина: каталог, фільтри, пошук, картки товарів, кошик і форма замовлення.
Сервер і база даних не потрібні, працює на будь-якому хостингу (зокрема безкоштовному GitHub Pages).

## Що вміє

- Каталог із категоріями, пошуком, сортуванням і фільтром «Лише в наявності»
- Картка товару з описом і характеристиками
- Кошик, який зберігається в браузері покупця
- Оформлення замовлення: ім'я, телефон, місто, доставка (Нова пошта / Укрпошта / самовивіз), оплата
- Замовлення відкривається в поштовій програмі покупця і надсилається на вашу пошту.
  Також його можна скопіювати й надіслати в месенджер.
- Адаптивний дизайн для телефона, планшета й комп'ютера, світла й темна теми

## Як змінити назву, контакти й товари

Усе редагується в одному файлі: `js/products.js`.

- `STORE` — назва магазину, телефон, e-mail для замовлень, Telegram, адреса, графік роботи
- `CATEGORIES` — список категорій
- `PRODUCTS` — товари: назва, ціна, стара ціна, наявність, опис, характеристики

### Фото товарів

Покладіть фото в папку `img/` і вкажіть шлях у товарі:

```js
{ id: "p1", name: "...", image: "img/phone1.jpg", ... }
```

Якщо фото немає, показується кольорова ілюстрація категорії (колір задає поле `color`).

## Як переглянути

Відкрийте `index.html` у браузері.

## Як опублікувати на GitHub Pages

1. Злийте гілку в `main`.
2. Відкрийте в репозиторії **Settings → Pages**.
3. У **Source** оберіть `Deploy from a branch`, гілку `main` і папку `/ (root)`.
4. За хвилину сайт буде доступний за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

## Структура

```
index.html        — сторінка
css/style.css     — стилі
js/products.js    — налаштування магазину й каталог
js/app.js         — логіка каталогу, кошика й оформлення
```
